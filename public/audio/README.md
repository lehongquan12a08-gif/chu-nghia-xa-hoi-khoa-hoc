# Âm thanh — Kháng chiến chống Pháp

| File | Vai trò |
|---|---|
| `ambient-lo.wav` | Nhạc nền không khí (tự tạo, đã nướng nhỏ sẵn cho mobile) |
| `sfx/chime.wav` | Tiếng "chime" khi chữ lớn xuất hiện (tự tạo) |
| `voice/part-1.m4a`, `voice/part-2.m4a` | **Lồng tiếng — CHƯA CÓ.** Thu xong đặt vào đây rồi điền mốc giây trong `data/narration.ts` |

Các file trong `sfx/` còn lại là di sản của dự án trước — có thể dùng làm tiếng
phụ họa theo chương bằng cách thêm vào mảng `SFX` trong
`components/AudioController.tsx`.
