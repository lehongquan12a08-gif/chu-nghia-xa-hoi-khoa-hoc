# ĐƯỜNG LỐI KHÁNG CHIẾN CHỐNG PHÁP (1946–1954)

Triển lãm số tương tác — kể chuyện bằng cuộn trang (scrollytelling) về đường lối
kháng chiến chống thực dân Pháp: **Toàn dân · Toàn diện · Trường kỳ · Tự lực
cánh sinh · Tranh thủ sự ủng hộ quốc tế.**

## Nội dung

| Giai đoạn | Điểm nhấn |
|---|---|
| Mở đầu | Landing lướt-xuống-hiện-chữ trên nền ảnh tư liệu |
| 1946 | 19/12 Toàn quốc kháng chiến · Lời kêu gọi · Pháo đài Láng |
| 1947–1949 | Việt Bắc Thu – Đông · giữ vững căn cứ địa |
| 1950 | Chiến dịch Biên giới · bước ngoặt |
| 1951–1953 | Phát triển thế và lực |
| 1953–1954 | Điện Biên Phủ · 56 ngày đêm · Toàn thắng 07/05/1954 |
| Ý nghĩa | Giơ-ne-vơ · giải phóng miền Bắc · 5 thành tựu |

Có **câu hỏi tương tác** (trắc nghiệm A/B/C/D) xen giữa các chương; câu hỏi
Điện Biên Phủ mở màn lá cờ "Quyết chiến – Quyết thắng".

## Chạy dự án

```bash
npm install
npm run dev   # http://localhost:3000
```

## Thêm lồng tiếng (khi thu xong)

1. Đặt file vào `public/audio/voice/part-1.m4a` (và `part-2.m4a` nếu có).
2. Điền mốc giây từng chương vào `data/narration.ts`.
