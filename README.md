# Từ tem phiếu đến mã QR

Web thuyết trình môn **MLN131 — Chủ nghĩa xã hội khoa học · Chương 3: Thời kỳ
quá độ lên chủ nghĩa xã hội ở Việt Nam**.

Scrollytelling điện ảnh: mạch trinh thám 4 hồi ("Thắng hai đế quốc mà thiếu gạo
— vì sao?"), bảng màu sepia bao cấp bừng màu tại Đại hội VI 1986, màn kéo gạt
phố xưa–nay, 8 thanh tiến độ dang dở của Cương lĩnh 2011, tự động lướt + lồng
tiếng khóa nhịp cuộn, nhạc nền tự soạn.

- Hướng dẫn làm việc nhóm + checklist ảnh/lồng tiếng: `HUONG-DAN-NHOM.md`
- Chạy thử: `npm install` rồi `npm run dev -- -p 3002`
- Nội dung đối chiếu Giáo trình CNXHKH (2021), Cương lĩnh 2011, Văn kiện Đại hội VI & IX

Thực hiện: **Lê Hồng Quân** (web) · **Phạm Thảo Nguyên** (lồng tiếng)
